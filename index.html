Materi Esensial

1. Pengertian SPtLDV

Sistem Pertidaksamaan Linear Dua Variabel (SPtLDV) adalah kumpulan dua atau lebih pertidaksamaan linear dengan dua variabel (misal x dan y) yang dicari penyelesaiannya secara bersama-sama.

  • Penyelesaian: pasangan (x, y) yang memenuhi semua pertidaksamaan dalam sistem.
  • Daerah penyelesaian: irisan seluruh daerah half-plane (setengah bidang) dari tiap pertidaksamaan pada bidang Kartesius.
x + 2y ≤ 102x + y ≤ 8x ≥ 0y ≥ 0

Contoh sebuah SPtLDV: keempat pertidaksamaan harus benar serentak.

2. Langkah Menentukan Daerah Penyelesaian

1
Gambar garis batas

Ubah tanda menjadi "=" lalu gambar garis melalui titik potong sumbu.

2
Pilih titik uji

Ambil titik di luar garis, misal (0, 0), substitusikan ke pertidaksamaan.

3
Arsir sisi yang benar

Jika pernyataan benar, arsir sisi yang memuat titik uji; jika salah, sisi sebaliknya.

4
Ambil irisan

Daerah yang terarsir oleh semua pertidaksamaan adalah daerah penyelesaian.

Catat: tanda ≤ atau ≥ → garis batas digambar penuh (titik pada garis ikut menjadi penyelesaian); tanda < atau > → garis batas putus-putus.

3. Contoh Terselesaikan

Tentukan daerah penyelesaian dari: x + y ≤ 62x + y ≤ 8x ≥ 0y ≥ 0

Garis x + y = 6 melalui (6, 0) dan (0, 6).
Garis 2x + y = 8 melalui (4, 0) dan (0, 8).

Titik uji (0, 0): 0 + 0 ≤ 6 (benar) dan 0 ≤ 8 (benar), sehingga daerah penyelesaian berada di sisi yang memuat titik O, dibatasi x ≥ 0 dan y ≥ 0.

Titik pojok: perpotongan x + y = 6 dengan 2x + y = 8 adalah B(2, 4). Daerah penyelesaian = segi empat O(0,0), A(4,0), B(2,4), C(0,6).

4. Memodelkan Soal Cerita

  • Langkah 1: tetapkan variabel, misal x dan y = banyaknya masing-masing produk.
  • Langkah 2: susun tabel kendala (bahan, waktu, biaya) per produk dan ketersediaannya.
  • Langkah 3: tulis pertidaksamaan tiap kendala, lalu tambah syarat wajar x ≥ 0y ≥ 0.
Mini contoh: Roti A butuh 200 g tepung dan 100 g mentega; roti B butuh 100 g tepung dan 150 g mentega. Tersedia 4.000 g tepung dan 3.000 g mentega. Model: 200x + 100y ≤ 4.000; 100x + 150y ≤ 3.000; x ≥ 0; y ≥ 0.

5. Tips Cepat

  • Titik potong sumbu: set y = 0 untuk potong sumbu x, dan x = 0 untuk potong sumbu y.
  • Titik uji (0, 0) paling cepat, selama tidak terletak pada garis batas.
  • Koefisien positif dengan tanda ≤ biasanya berarti daerah bawah garis; ≥ berarti daerah atas.
  • Periksa titik pojok dengan eliminasi/substitusi dua garis batas yang berpotongan.

Peta Konsep dalam Satu Gambar

Amati alur dan warna: tiap pertidaksamaan menyumbang satu arsiran; irisan semua arsiran (biru pekat) adalah daerah penyelesaian.

A
Warna = pertidaksamaan

Biru: x + 2y ≤ 10. Kuning: 2x + y ≤ 8. Arsiran tipis = sisi yang benar.

B
Irisan = jawaban

Hanya daerah yang terkena semua arsiran yang menjadi daerah penyelesaian.

C
Titik pojok

Perpotongan dua garis batas; berguna untuk memeriksa dan untuk soal optimum.

Naskah Narasi

Sistem pertidaksamaan linear dua variabel adalah kumpulan dua atau lebih pertidaksamaan linear dengan dua variabel yang diselesaikan bersama-sama. Penyelesaiannya berupa pasangan x dan y yang memenuhi semua pertidaksamaan. Daerah penyelesaian diperoleh dengan menggambar garis batas tiap pertidaksamaan, menguji sebuah titik, mengarsir sisi yang memenuhi, lalu mengambil irisan seluruh arsiran. Tanda kurang dari atau sama dengan, serta lebih dari atau sama dengan, digambar dengan garis penuh. Pada soal cerita, kendala banyaknya benda menambah syarat x dan y tidak negatif. Pengaturan

Jika diisi, setiap kiriman siswa juga dikirim otomatis ke Google Sheets Anda, sehingga jawaban dari perangkat siswa mana pun terkumpul.

Panduan singkat sinkronisasi online (5 langkah)
  1. Buat Google Sheets baru, menu Ekstensi > Apps Script.
  2. Tempel kode di bawah ini, lalu simpan.
  3. Deploy > New deployment > Web app; Execute as: Me; Who has access: Anyone. Salin URL web app.
  4. Tempel URL tersebut pada kolom di samping, klik Simpan.
  5. Unduh HTML versi siswa dan bagikan file itu ke perangkat siswa; kiriman mereka masuk ke Sheets dan folder Drive Anda.
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName('Data') || ss.insertSheet('Data');
  var link = '';
  if (d.file && d.file.base64) {
    var it = DriveApp.getFoldersByName('SPtLDV_Jawaban');
    var folder = it.hasNext() ? it.next() : DriveApp.createFolder('SPtLDV_Jawaban');
    var blob = Utilities.newBlob(Utilities.base64Decode(d.file.base64), d.file.type || 'application/octet-stream', d.file.name);
    link = folder.createFile(blob).getUrl();
  }
  sh.appendRow([new Date(), d.nama || '', d.kelompok || '', d.jenis || '', d.ket || '', link]);
  return ContentService.createTextOutput('OK');
}
